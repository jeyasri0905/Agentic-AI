# Gemini Calculator Agent (Agentic AI Practice)

A pure, zero-framework implementation of an **Agentic AI Calculator** powered by Google's official `google-genai` SDK and Gemini 2.5 Flash.

---

## 📁 Project Structure

```
gemini_calculator_agent/
├── app.py                  # Main agent script with the agentic loop
├── calculator_tool.json    # Calculator tool definition formatted in JSON Schema
└── README.md               # Instructions and documentation
```

---

## 🛠️ How It Works (Agentic AI Architecture)

1. **JSON Tool Schema (`calculator_tool.json`)**:
   Defines the calculator tool format, parameters (`operation`, `a`, `b`), and acceptable values (`add`, `subtract`, `multiply`, `divide`, `power`).
2. **User Input**:
   The user sends natural language queries (e.g. *"What is 45 * 89?"* or multi-step questions like *"Add 25 and 75, then divide by 5"*).
3. **LLM Decision (Tool Call)**:
   The Gemini model analyzes the query and decides to call the `calculator` tool with arguments extracted into JSON.
4. **Local Tool Execution**:
   The Python agent intercepts the tool call, reads the JSON arguments generated by the LLM, executes `execute_calculator()`, and gets the computation result.
5. **Tool Response to LLM**:
   The agent hands the tool output back to the LLM.
6. **Final Synthesis**:
   The LLM generates the final natural language answer to the user.

### Step 1: Add Your Gemini API Key
Open [app.py](file:///C:/Users/Admin/.gemini/antigravity/scratch/gemini_calculator_agent/app.py) and replace the placeholder:
```python

```
*Alternatively, you can set the environment variable `GEMINI_API_KEY`.*

### Step 2: Run the Agent
Open a terminal in the project directory and execute:
```bash
py app.py
```
